# OpenMAIC 双模型协同独立测试版（2026-10-24）

本副本基于当前原项目 `D:\OPENMAIC项目\OpenMAIC\OpenMAIC-main`，不基于此前的 16K 测试副本。原项目的源码、模型配置、数据库均不改动。

## 如何测试

1. 先关闭原版或 16K 版正在生成的课程，避免它们与本副本争抢同一张显卡。无需删除旧版。
2. 在本目录双击 **启动双模型协同测试版.cmd**（本目录的“启动平台.cmd”也指向同一测试启动器）。
3. 浏览器访问 **http://127.0.0.1:3200**，保留启动窗口。
4. 重新生成课堂。独立数据库不会自动导入或修改旧课堂；目前仅保存了一节两页讲义验证课。
5. 停止时在启动窗口按 Ctrl+C，或双击“停止双模型测试版.cmd”。继续用旧版时，去原项目目录启动旧版即可，无需改回模型配置。独立测试数据库在后台保留，便于下次打开。

模型准备完毕后可以断网测试；本副本只调用本地 Ollama，不使用云端推理 API。浏览器语音取决于 Windows 已安装的本地语音，不保证系统的所有语音选项都支持离线。浏览器原生语音识别可能需要网络，断网时请使用文字输入。

## 两个模型怎么分工

| 工作 | 模型 / 执行方式 |
| --- | --- |
| 大纲、课程角色、随堂检测、原生互动页 | 原有 `qwen2.5-coder:7b` |
| 原生 PPT 正文生成、页面讲解动作与旁白 | `openmaic-gemma4-e4b:dual-16k`，基于 `gemma4:e4b-it-qat`，16K 上下文、关闭思考 |
| 课堂讨论、导演和工具 Agent | 原有 Qwen |
| Python Lab 出题、代码生成与修复 | 原有 Qwen |
| 算法推演、参考答案验证与学生代码评测 | 保留项目现有执行器及沙箱 |

采用框架已有的模型槽分流，课程阶段继续传递原生大纲和已有上下文。这里的协同是不同模型分工完成同一课堂，不是两个模型互相投票。维护库直接生成的讲解页、实验页不需要调用 Gemma；不要把这些页的质量变化全部归因于换模型。

两个模型共用一张 8GB 显卡，因此通过本地串行队列依次运行，切换前卸载本队列的上一个模型。模型切换有耗时，本版不保证比单模型更快，也不保证生成内容全部正确；请比较实测质量、失败次数和总耗时。
