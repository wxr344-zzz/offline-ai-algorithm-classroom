# 算法推演覆盖与验收清单

本清单按本次约定的 408 数据结构基准与自命题扩展编排，不表示对某年某校招生目录的认证。目录、输入约束与默认示例由 `exam_simulator` 的维护代码定义；课堂选择算法后只发送 JSON 数据，不运行模型生成的算法代码。

## 正确性边界

- 每一步由固定 Python 函数计算；快照深复制，回退不会改变过去的数据。
- 背包三种取物约束分别实现。完全背包选择来自本行，0-1 来自上一行。
- Alpha-Beta 仅在 `alpha >= beta` 且尚有未访问孩子时剪枝；根结果与完整 Minimax 独立核对。
- 树每次完整操作后核对中序集合与父指针；AVL 核对平衡因子；红黑核对根黑、红子黑、等黑高；B/B+ 核对占用、叶深度、分隔键与叶链。
- 最短路与生成树包含独立参考核验；排序核对原元素及重复次数。非连通图输出森林/不可达，而非伪造有限距离。
- A* 当前教学配置采用一致启发式；Dijkstra 不接受负边。输入违反算法前提时明确报输入错误，不伪造推演。
- 教学输入有规模上限（例如最多 3000 帧），用于完整展示手算步骤；不是无限规模性能演示。不同输入格式/算法变种须在目录中选定对应配置，不能凭相近名称替代。

## 验证入口

`tests/test_exam_simulator.py`：全部目录默认示例、快照隔离、六类查找树随机序列与五类交错操作、排序重复/空输入、随机图、Alpha-Beta 与 Minimax、非二次幂归并、接口认证和模型隔离。

`tests/edit/decorative-text-clearance.test.ts`：只移动覆盖文字的细橙色装饰条；不改文字、排版、其他颜色；已有课件加载时修正。

旧课堂迁移脚本 `scripts/refresh-algorithm-widgets.ts` 先备份原文档，在所有者和版本围栏内保存，按深度等价性复核持久化结果。实验题面、学生代码和成绩表不在此次迁移范围。
