# 基于 OpenMAIC 的离线 AI 算法课堂

基于开源 OpenMAIC 二次开发的本地双模型互动课堂，将算法讲解、执行推演、编程练习和反馈连接起来。作品参加 2026 第八届全球校园人工智能算法精英大赛·算法主题赛 **AI+开源**赛道，方向为“开源项目改进与生态贡献”。

## 核心思路

**模型负责讲、程序负责算。** 模型负责课程内容及交互生成；算法推演状态和编程练习的评测结果来自实际程序执行。预置算法使用确定性执行器；目录外主题通过模型生成候选程序，并在 WASM 沙箱中运行校验后使用。

## 功能

- **算法推演**：78 项预置算法，提供逐步状态展示；支持目录外主题的动态生成与沙箱校验。
- **两级编程实验**：引导编程和自主编程，浏览器内通过 Pyodide 运行 Python；自定义运行与公开测试分离，支持 Notebook 导出。
- **本地双模型**：Gemma 4 E4B 侧重课件和讲解，Qwen2.5-Coder-7B 负责大纲、测验、讨论调度及实验等任务；串行推理网关使用 16K 上下文运行别名。
- **离线课堂**：完成环境、资源与模型准备后，可在断网环境中运行。
- **资源导出**：支持课件、Notebook 等多种格式导出。

## 环境要求

- Windows；Node.js 22.19 或以上（记录的测试版本为 24.21.0）与 pnpm 10。
- Python 3.11、PostgreSQL 15 或以上、Ollama。
- 约 8 GB 显存的 GPU；实际需求受模型、上下文和运行配置影响。
- 从官方渠道获取 Gemma 4 E4B 与 Qwen2.5-Coder-7B 模型权重。

具体版本记录见 [交付说明/运行环境版本记录.json](交付说明/运行环境版本记录.json) 和 [离线部署说明](离线部署说明.md)。

## 快速开始

首次准备运行环境需要联网一次。在 Windows 上依次运行：

1. `准备运行环境.cmd`：安装并准备依赖、数据库和构建。`pnpm install` 会构建 packages；`pnpm build` 在浏览器资源缺失时下载并校验 Pyodide、Monaco 等资源。
2. `准备本地模型.cmd`：准备本地模型与 16K 运行别名。
3. `离线自检.cmd`：检查运行环境。
4. `启动平台.cmd`：启动后访问 [http://127.0.0.1:3400](http://127.0.0.1:3400)。

`.env.local` 和 `database-runtime.json` 由准备流程在本机生成，不随仓库提供。准备完成后可断网运行。

需要在完全离线环境部署时，可下载 [Release](../../releases/tag/v1.0.0-competition) 中的完整源码包，其中包含已准备好的浏览器运行资源；Node / Python 依赖、数据库运行环境及模型权重仍需事先在目标环境准备。

## 已知限制

- 讨论区偶发显示原始 JSON 文本（演示视频约 1:20–1:46 可见）。
- 普通主题测验仍可能有语义错误；未收录算法的生成成功率依赖本地 7B 模型。
- 正式判题（服务端隔离运行器）按决定暂缓，当前浏览器评测仅作练习反馈。
- 编程实验只支持 Python；Java、C++ 等课程的实验仍为 Python。
- 离线时浏览器语音输入不可用（依赖厂商在线服务）。
- 完整生成耗时缺少按固定配置的计时数据。
